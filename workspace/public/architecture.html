safety_check_node ALWAYS FIRST
每轮必过的关卡 — 重置临时状态字段，决定下一跳路由
🔴 注入攻击拦截 正则匹配 prompt injection / script 等 7 种模式 → 返回拒绝消息，END
🟡 多轮续接 awaiting_order_id ≠ "" → 直接跳转 order_read / order_write 绕过 router，省一次 LLM 调用
🟠 关键词人工转接 正则检测"转人工/要投诉/人工客服"等 12 种模式 → human_escalation_node (无需 LLM)
router_node — 意图分类器 LLM · function_calling
分析最近 6 条消息，返回结构化 IntentClassification{intent, confidence}
置信度 < 0.55 → fallback general_node（防止低质量路由）
product_node
商品推荐 / 款式咨询
  • Tool calling × 3
  • list / search / detail
  • 查商品数据库
  • 最多推荐 3 款
  • 含价格 + 周期
faq_node
政策 / 流程 / 知识
  • Hybrid RAG
  • BM25 + PGVector
  • 注入 order_context
  • 最近 8 条消息
  • 无 order→通用知识
order_read_node
查询订单（只读）
  • 提取 order_id
  • 无ID→询问并续接
  • get_status
  • get_production_progress
  • get_tracking
  • 写 order_context
order_write_node ⭐
写操作 + HITL 审批
  • 提取 action + order_id
  • 预验证（Pre-check）
  • cancel / refund / rush
  • interrupt() → HITL
  • 批准→执行写DB
  • 拒绝→友好收场
HITL interrupt()
Pre-validation 通过后暂停图执行
前端收到 status=interrupted
工作台弹出审批面板
✓ 批准 → execute()
✗ 拒绝 → 取消消息
POST /chat/{thread_id}/resume
{approved: bool, reviewer_notes}
aftersales_node
质量投诉 / 售后问题
  • 同理心首先
  • 收集三要素：
  • order_id + 问题 + 婚期
  • ≤14天→紧急热线
  • 引导 order_write
general_node
问候 / 闲聊 / 兜底
  • 低置信度 fallback
  • 问候/感谢/闲聊
  • negative_turns 计数
  • ≥4轮→建议转人工
  • 超范围→礼貌拒绝
▸ 人工转接路径（safety 直接触发，绕过 router）
