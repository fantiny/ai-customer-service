🔑 身份体系说明：前台（客户）与后台（客服）的登录身份完全独立，互不影响。
👤 前台 · 客户身份 JWT token（或 ?user= 访客） socket 事件：join → 发起对话
👔 后台 · 客服身份 Agent ID + 姓名（工作台表单填写） socket 事件：join_workspace → 进入工作台
点击下方"打开工作台"按钮可直接进入后台视图，在工作台登录表单填入对应的 Agent ID 与姓名即可。
URL 自动携带 ?view=agent，直接显示后台界面

📖 测试步骤

  1. 点击上方 打开工作台，在新窗口进入后台界面。
  2. 复制下方任一 Agent ID（如 agent_li_hong）并在工作台登录表单填入姓名后提交。
  3. 回到 👤 测试用户 标签，用客户身份发起对话。
  4. 工作台将实时显示进来的会话；客服可认领、回复、审批 HITL 请求、结单。
  5. 前台与后台身份完全独立——关闭工作台不影响客户对话，反之亦然。
