## 二、核心测试场景（AI 自动处理）

### 场景 1：订单进度查询（最高频）

**测试用户**：`user_chen_fang`  
**话术示例**：
```
我的婚纱做到哪里了？
订单 WD-2025-0001 进展如何？
还有多久能做好？
```
**预期**：AI 查询 orders 表，返回 WD-2025-0001 当前阶段（缝制中），预估完工时间

---

### 场景 2：物流查询

**测试用户**：`user_li_mei`（已发货）或 `user_huang_ting`  
**话术示例**：
```
我的婚纱发货了吗？
快递单号是多少？
什么时候能到？
```
**预期**：AI 返回快递单号 SF7890001234567，提示可通过顺丰官网查询

---

### 场景 3：婚期紧张·加急咨询

**测试用户**：任意新用户  
**话术示例**：
```
我婚礼是下个月 15 号，还能定制婚纱吗？
如果加急的话要多少钱？
星河鱼尾加急 30 天要多少钱？
```
**预期**：AI 查询 FAQ 加急政策，计算 ¥12,800 × 50% = 加急费 ¥6,400，给出明确报价

---

### 场景 4：款式推荐

**测试用户**：任意新用户  
**话术示例**：

**预期**：AI 检索 product_catalog，结合体型/场合/预算推荐合适款式

## 三、人工客服场景（需 HITL/人工介入）

### 场景 10：质量投诉

**测试用户**：`user_luo_jia`（已签收，质量问题）  
**话术示例**：
```
我收到的婚纱有好多线头，质量太差了！
蕾丝都脱落了，这是怎么回事
我要投诉，这婚纱根本没法穿
```
**预期流程**：
1. AI 安抚，询问具体问题和照片
2. 客户情绪激动时，AI 主动转接人工
3. 工作台显示 AI 摘要：质量投诉、蕾丝脱落、客户情绪不满
4. 人工客服按质量投诉标准处理

---

### 场景 11：颜色不符投诉

**测试用户**：`user_xiong_yun`（已签收）

## 四、工作台功能测试

### 测试 A：多 session 并发管理
同时打开两个浏览器标签，用不同用户 ID 开始对话，
验证工作台能同时显示多个 session，客服可切换处理

### 测试 B：HITL 审批流程
1. 用 `user_chen_fang` 说"取消订单"
2. 工作台弹出 HITL 审批卡片
3. 客服点击"批准"，AI 执行取消
4. 客服点击"拒绝"，AI 告知客户审批未通过

### 测试 C：转人工接管
1. 用 `user_luo_jia` 发质量投诉
2. AI 转接人工后，工作台显示接入通知
3. 客服在工作台输入框回复
4. 客户端显示"小美"的回复
5. 测试双向打字指示器（客服和客户都能看到对方正在输入）

### 测试 D：结单与评分
1. 处理完 `user_luo_jia` 的投诉
2. 客服点击"结单"按钮，填写解决方案
3. 客户端弹出 CSAT 评分弹窗（1-5星）
4. 提交评分后，查询 `/api/workspace/tickets/{ticket_id}` 验证 rating 字段

### 测试 E：SLA 告警
在工作台等待超过 2 分钟不处理任何 HITL 任务，
验证 `sla_warning` 事件推送（工作台标红显示）

## 五、API 测试速查

```bash
# 查看所有待处理工单
curl http://localhost:8000/api/workspace/tickets

# 按状态筛选（已结单）
curl "http://localhost:8000/api/workspace/tickets?status=resolved"

# 今日统计
curl http://localhost:8000/api/workspace/metrics/today

# 7天分析报告（核心：含 intent 分布、CSAT）
curl http://localhost:8000/api/workspace/analytics

# 会话完整消息链（conversation replay）
curl http://localhost:8000/api/workspace/sessions/{session_id}/messages

# 查看特定工单时间线
curl http://localhost:8000/api/workspace/tickets/{ticket_id}/events

# 查询特定订单（用于订单 AI 测试）
# user_id 填入 user_chen_fang，thread_id 用任意字符串
curl -X POST http://localhost:8000/api/chat \
  -H "Content-Type: application/json" \
  -d '{"user_id":"user_chen_fang","thread_id":"test-001","message":"我的婚纱做到哪里了"}'
```
